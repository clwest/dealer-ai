## What this project is

Freedom Ford Dealer AI — a budget-constrained vehicle-recommendation chat
assistant running on local Ollama llama3.2 (3.2B). Architecture is deterministic
backend math (payment engine, candidate classifier, inventory selection) plus a
16-stage post-LLM scrub pipeline plus state-layer enforcement (intent-shift
reset, sticky cash mode, weak-intent budget inference) wrapping a tightly
prompted local LLM. Frontend has a live banner + per-message framing label.
Onboarding foundation page exists; not yet persisted to the backend.
